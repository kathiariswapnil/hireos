Architecture

A durable state machine, not one giant autonomous prompt

Every requisition is a workflow instance with versioned state, replayable events and retries. This is what makes the system auditable, and what makes it survive a failed model call.

Terminal statesHIREDREJECTEDCLOSED

Amber states require a recorded human decision before the workflow can advance.

Durable

Every requisition is a workflow instance with versioned state. It survives restarts, retries and failed model calls.

Evented

Every transition emits an event, which gives you replay and a complete workflow history rather than a final status.

Gated

Amber states cannot advance without a recorded human decision. Not a setting — a property of the state machine.

Agent architecture

Specialized agents with scoped tool permissions

No agent gets unrestricted authority. Each one receives only the tools its job requires — which is what turns a demo into something an enterprise security review will pass.

  • Interview structures per role and level
  • Org roles, levels and approval hierarchy
  • Relevant historical hiring context

The discipline that matters

Historical hiring decisions are not ground truth. History carries bias and inconsistency, so the product separates historical pattern from approved policy and treats the past as context, never as authority.

Retrieval is permission-aware. A manager cannot reach a policy they are not entitled to see, which is a requirement rather than a feature.

API surface

Everything the workflow does is an endpoint

The product is an API with a UI on top, which is what makes it embeddable in a stack a customer already runs.

  • POST/v1/requisitionsCreate hiring request.
  • POST/v1/requisitions/{id}/generate-jdGenerate JD from company knowledge.
  • POST/v1/jds/{id}/approveApprove JD.
  • POST/v1/jds/{id}/commentSend JD revision comments.
  • POST/v1/jobs/{id}/publishPublish approved job through connector.
  • GET/v1/jobs/{id}/candidatesList applications and candidates.
  • POST/v1/applications/{id}/evaluateRun candidate intelligence.
  • POST/v1/applications/{id}/shortlistRecord human shortlist decision.
  • POST/v1/interviews/scheduleRequest scheduling.
  • POST/v1/interviews/{id}/feedbackSubmit or approve feedback.
  • POST/v1/offers/generateGenerate offer draft.
  • POST/v1/offers/{id}/approveApprove offer.
  • GET/v1/audit/{entity}/{id}Retrieve audit history.
